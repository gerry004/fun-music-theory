# Solfa

Solfa is a small, playful music-theory studio for building fluent note-reading skills. It currently includes two practice modes across treble and bass clefs:

- **Lives mode** — identify 15 notes with five lives.
- **Tempo mode** — read as many notes as possible in 30 seconds.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
```

Solfa is built with Next.js, React, TypeScript, and Tailwind CSS.
